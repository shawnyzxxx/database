## 一、作业说明
原作业按题号 1～15 依次布置，主要围绕**数据库的创建、表的建立与基础 SQL 操作**展开。由于原笔记仅保留了题号，下面把这一阶段应掌握的数据库基础操作整理如下。

## 二、核心知识点梳理
**1. 连接与选择数据库**
```sql
mysql -u root -p
USE mydb7_openlab;
```

**2. 创建数据库与表**
```sql
CREATE DATABASE mydb7_openlab;
USE mydb7_openlab;
CREATE TABLE goods (
  gid VARCHAR(10) PRIMARY KEY,
  name VARCHAR(50),
  price DECIMAL(10,2),
  onum INT
);
```

**3. 插入与查询数据**
```sql
INSERT INTO goods (gid, name, price, onum) VALUES ('a0001', '橡皮', 2.5, 10);
SELECT * FROM goods;
```

**4. 更新与删除**
```sql
UPDATE goods SET onum = 5 WHERE gid = 'a0001';
DELETE FROM goods WHERE gid = 'a0001';
```

**5. 查看表结构与库信息**
```sql
DESC goods;
SHOW DATABASES;
SHOW TABLES;
```

## 三、小结
本次作业覆盖了 MySQL 的基础 DDL 与 DML 操作。建议对照题号逐条完成练习，并熟记 `CREATE/INSERT/SELECT/UPDATE/DELETE` 五类基础语句的写法，为后续的索引、视图、触发器和存储过程打基础。
