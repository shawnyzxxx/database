# 数据库实践第一次作业：MySQL 8.0 安装与建库建表

## 文章导读
本篇是数据库实践的第一次作业，完整记录在 Windows 上**安装 MySQL 8.0、初始化并设置 root 密码、创建数据库与三张业务表**的全过程。适合第一次接触 MySQL、需要搭建本地数据库环境的读者。

## 一、起始准备：安装 MySQL 8.0

**1. 下载 MySQL 8.0 的 .msi 安装包**
访问 MySQL 官网 https://dev.mysql.com/downloads/mysql/ ，选择适用于 Windows 的 `.msi` 格式安装包下载。

**2. 运行安装程序**
下载完成后，双击 `.msi` 文件开始安装。

**3. 配置安装路径**
安装过程中会提示选择安装路径，建议使用**英文路径**，以免出现错误。

**4. 设置环境变量（可选）**
若希望在命令行直接运行 MySQL 命令，可以配置环境变量：右键「此电脑」→「属性」→「高级」→「环境变量」，在系统变量中找到 `Path`，添加 MySQL 的 `bin` 目录。

**5. 启动 MySQL 服务**
安装完成后，可通过控制面板或命令行启动服务：

```cmd
net start mysql     # 启动服务
net stop mysql      # 停止服务
```

**6. 初始化 MySQL 并设置 root 密码**
首次启动后需要初始化并设置 root 密码：

```cmd
# 初始化
mysqld --initialize --console
```
```sql
-- 设置 root 密码
ALTER USER 'root'@'localhost' IDENTIFIED BY 'newpassword';
```
> 注意原稿中 `idetified` 为 `IDENTIFIED` 的拼写错误，命令应以正确拼写执行。

**7. 验证安装**
使用新设置的 root 密码登录，验证安装是否成功：

```cmd
mysql -uroot -p
```

**8. 配置 MySQL**
创建用户、数据库等基本配置可根据需要后续进行。

## 二、创建步骤

**1. 连接 MySQL 服务器**
打开 Windows PowerShell，登录 root 账户：

```sql
mysql -u root -p
```

**2. 创建数据库 mydb6_product**
```sql
CREATE DATABASE mydb6_product;
```

**3. 选择数据库**
```sql
USE mydb6_product;
```

**4. 创建 employees、orders、invoices 三张表**
```sql
CREATE TABLE employees (
  id INT PRIMARY KEY,
  name VARCHAR(50) NOT NULL,
  age INT,
  gender VARCHAR(10) NOT NULL DEFAULT 'unknown',
  salary FLOAT
);

CREATE TABLE orders (
  id INT PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  price FLOAT,
  quantity INT,
  category VARCHAR(50)
);

CREATE TABLE invoices (
  number INT AUTO_INCREMENT PRIMARY KEY,
  order_id INT,
  in_date DATE,
  total_amount FLOAT CHECK (total_amount > 0),
  FOREIGN KEY (order_id) REFERENCES orders(id)
);
```
> `invoices` 表通过外键 `order_id` 关联 `orders` 表，并使用 `CHECK` 约束保证金额为正。

**5. 查看数据库和表**
```sql
SHOW DATABASES;
USE mydb6_product;
SHOW TABLES;
```
