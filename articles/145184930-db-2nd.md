# 数据库第二次

## 文章导读
本篇是数据库课程的第二次作业，围绕 `t_worker`（员工）表，系统练习**单表查询、聚合统计、子查询、排序分页、分组过滤**等 MySQL 核心查询语法，是 SQL 查询入门阶段的重要练习。

## 一、作业说明
以 `t_worker` 表为基础，按题号 1～15 完成查询。表结构大致包含字段：`worker_id`（工号）、`name`（姓名）、`department_id`（部门号）、`wages`（工资）、`birth_date`（出生日期）、`politics`（政治面貌）、`worker_date`（入职日期）等。

## 二、参考 SQL
**1. 查询全部员工**
```sql
SELECT * FROM t_worker;
```

**2. 查询不重复的部门编号**
```sql
SELECT DISTINCT department_id FROM t_worker;
```

**3. 统计员工总数**
```sql
SELECT COUNT(*) FROM t_worker;
```

**4. 查询最高工资与最低工资**
```sql
SELECT MAX(wages) AS '最高工资', MIN(wages) AS '最低工资' FROM t_worker;
```

**5. 查询平均工资与总工资**
```sql
SELECT AVG(wages) AS '平均工资', SUM(wages) AS '总工资' FROM t_worker;
```

**6. 通过查询创建表 work_date**
```sql
CREATE TABLE work_date AS SELECT worker_id, name, worker_date FROM t_worker;
```
> 该语句属于 `CREATE TABLE ... AS SELECT`，会把查询结果直接写入新表。

**7. 计算党员年龄**
```sql
SELECT name, TIMESTAMPDIFF(YEAR, birth_date, CURDATE()) AS age
FROM t_worker WHERE politics = '党员';
```

**8. 查询工资在 4000～8000 之间的员工**
```sql
SELECT name FROM t_worker WHERE wages BETWEEN 4000 AND 8000;
```

**9. 查询姓孙或姓车的员工**
```sql
SELECT name FROM t_worker WHERE name LIKE '孙%' OR name LIKE '车%';
```

**10. 查询 102、103 部门且非党员的员工**
```sql
SELECT worker_id, name FROM t_worker
WHERE department_id IN (102, 103) AND politics <> '党员';
```

**11. 按出生日期排序**
```sql
SELECT * FROM t_worker ORDER BY birth_date;
```

**12. 按工资降序取前 3 名**
```sql
SELECT worker_id, name FROM t_worker ORDER BY wages DESC LIMIT 3;
```

**13. 按部门统计党员人数**
```sql
SELECT department_id, COUNT(*) AS 党员人数
FROM t_worker WHERE politics = '党员' GROUP BY department_id;
```

**14. 按部门统计总工资与平均工资**
```sql
SELECT department_id, SUM(wages) AS 总工资, ROUND(AVG(wages), 2) AS 平均工资
FROM t_worker GROUP BY department_id;
```

**15. 按部门统计总人数，仅保留人数 ≥3 的部门**
```sql
SELECT department_id, COUNT(*) AS 总人数
FROM t_worker GROUP BY department_id HAVING COUNT(*) >= 3;
```

## 三、小结
本次作业覆盖了单表查询的完整能力：从基础的 `SELECT`、`DISTINCT`，到聚合函数（`MAX/MIN/AVG/SUM/COUNT`），再到分组（`GROUP BY`）与过滤分组结果（`HAVING`），以及排序（`ORDER BY`）和分页（`LIMIT`）。熟练掌握这些查询是编写复杂 SQL 的基础。
